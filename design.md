# QBF Wireless Split Perkins Keyboard

1.  This is a Perkins style keyboard.
    1.  8 keys are mapped to the 8 braille dots that make up a Braille cell.
    2.  These keys can be pressed together in different combinations to type
        different Braille cells.
    3.  They are pressed at the same time as part of a chord.
    4.  The space bar may also be used as part of chords, commonly for computer
        interaction.
